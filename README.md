# TaskFlow

A simple full-stack task management application built to learn and practice frontend, backend, API, and database development.

## 🚀 Features

- Add tasks
- Mark tasks as completed
- Delete tasks
- Search tasks
- Filter tasks
- Task statistics
- Dark mode
- Responsive design

## 🛠️ Technologies Used

### Frontend
- HTML
- CSS
- JavaScript

### Backend
- Node.js
- Express.js

### Database
- SQLite
- better-sqlite3
